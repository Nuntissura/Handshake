<topic id="cross-crate-patterns" status="current" updated_at="2026-10-11T00:59:59Z" summary="Dependency graph, shared identity and cancellation types, reservation and two-phase finalize patterns, inconsistencies">

- **Reservation pattern (RAII retirement on Drop):** `reserve(bytes, limit)` returns a guard that retires synchronously with no reduction escape. Instances: type admission.rs:10-38 and 54-70; nib proposal.rs:49-59; prism admitted.rs:29-39 (`synchronous_retirement`); pigment masked_patch.rs:40-68 (`RetirementContext`) and caller.rs:105 (`reserve`).
