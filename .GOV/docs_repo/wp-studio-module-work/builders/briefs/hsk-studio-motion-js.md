## Minimal slice (provider port is `motion`'s; this crate = pure-Rust profile validator + ONE real engine backend candidate behind a feature; ~900-1300 LOC)
Reuse (verified): `hsk_studio_accord::{CancellationToken, ActorContext, Ticks, TICKS_PER_SECOND}`; `hsk_studio_observe::{Observe, Observation, Outcome, FailureCode, SinkPort}`; from `hsk-studio-motion` (once landed): `ExpressionProvider`, `HostRead`, `ExprRequest`, `Fuel`, `ExprError`, `EvalTick`, `PropertyPath`, `DateProfile`.
1. Profile validator (pure Rust, no engine, deterministic): `pub fn validate_source(src:&str, profile:&ProfileV1) -> Result<ValidatedSource, ExprDiag>` parses with `boa_parser 0.22.0` (pure-Rust ECMAScript parser, same release train as Boa; behind feature `parse`) and walks the `boa_ast` visitor with an ALLOWLIST of node kinds; anything else => `ExprDiag::Unsupported{kind, span:{line,col,len}}`: `eval`/`Function`/`new Function`/`.constructor`/`__proto__`/`Proxy`/`Reflect`/`import`/`await`/`async`/`yield`/`Promise`/`setTimeout`/`with`/getters-setters/classes/tagged templates/regex literal (initially) etc. Output carries `source_sha256`, `profile_id`, and a source map (span table) for later diagnostics. 2. Engine backend A (pure Rust, feature `engine-boa`, default OFF): `boa_engine 0.22.0`: one fresh `Context` per evaluation (clean realm; no state survives samples), `RuntimeLimits`: nonzero `set_loop_iteration_limit(fuel)`, `set_recursion_limit`, `set_stack_size_limit` (docs.rs `vm::RuntimeLimits` checked: loop/recursion/stack/backtrace only - NO heap limit); remove/shadow ambient globals (`Math.random` throws, no `Date` clock - install the host `DateProfile` instant instead, no `console`, no `eval`/`Function` constructor reachability checked by intrinsic probe); register ONE host function `hostRead(path)` bound to the immutable `HostRead` with `PropertyPath` validation, charging the shared `Fuel`; evaluate `1+2` => `[3.0]` and a host field read => the independently supplied canonical value; convert the result ONLY from number | array-of-number | (bounded) with node/depth/byte caps, rejecting objects, getters, proxies, `NaN`/`Infinity` (`OutputType`), never promoting partial output.
3. Provider implementation: `pub struct MotionJsProvider<E: Engine>` implementing `motion::ExpressionProvider::evaluate`: validate -> engine eval -> map engine failures to typed `ExprError::{Parse, Unsupported, Budget, Cycle, ReferenceMissing, OutputType, Canceled}` with spans; a thrown JS error NEVER escapes as a panic or a value (STU-MOT-078: disabled-by-error + fallback is applied by `motion::Property::evaluate_with`); retries share the original `Fuel`; cancel polled before parse/eval and via the loop limit; `retire(self) -> RetireReport{context_dropped, permits_released, thread: Owner}` consumes the single owner on the owning thread.

Only start B after A passes its tests.
5. `DESCRIPTOR` JSON (profile id, allowlist summary, engine identity incl. versions/features, limits table, `NOT_PROVEN` items: aggregate worker RSS/CPU/deadline [needs a separate worker process, next slice, same isolation pattern as score-plugin], heap bomb, 333-identifier coverage, cached-compile identity) + `report(...)` into `Observe` (Success/Canceled/Failure(Validation|Unsupported|Loss)) + example `motion-js-consumer` (`--descriptor`, `--validate "src"`, `--eval "1+2"`, `--engine boa|quickjs`, `--fuel N`).

## Tests (<=5, `bounded_case`, per-test deadline well below the 30 s default for hostile sources)
1. `validator_allowlist_and_spans`: accepted profile samples (`1+2`, ternary, `for` with lexical `let`, closure) pass; each denied construct (`eval("1")`, `Function("return 1")`, `(()=>{}).constructor("return 1")`, `new Proxy({}, {})`, `async function f(){}`, `import("x")`, `with(a){}`, getter literal) returns `Unsupported` with the exact line/col span; oversize source rejected before parse.
2. `engine_boa_evaluates_and_reads_host`: `1+2` => `[3.0]`; `hostRead("comp/layer/transform/position")` equals the fixture value; a second sample in the same provider sees NO state from the first (global assigned in sample 1 absent in sample 2); `Math.random()` and ambient `Date.now()` are unavailable or return the injected deterministic value.
3. `budget_and_depth_denials`: `while(true){}` => `Budget` (loop limit from `Fuel`), `function f(){f()} f()` => `Budget` (recursion/stack limit), retries share the original allowance (second attempt fails faster), nested host reads charge the same `Fuel`; zero/unlimited limits rejected at configuration time (fail closed).
4. `output_and_cycle_rules`: result object / getter / `NaN` / oversize array => `OutputType`, no partial output; host-read cycle A->B->A => `Cycle` naming paths (via motion's graph); thrown JS error => typed `ExprError` with span, no panic; cancel before eval => `Canceled`.
5. `retire_and_differential` : `retire()` consumes the owner and reports `context_dropped && permits_released`; when `engine-quickjs` is enabled the same suite 2-4 runs on rquickjs and results are identical; heap-bomb test (`new Array(1e9)`) is `#[ignore]` + marked `NOT_PROVEN` until a worker-process RSS limit exists.
