## [SFR-PROVIDER-POSTURE] Provider Posture Map

### [SFR-PROVIDER-POSTURE.policy] Classification Policy

```yaml
posture_policy:
  local_primitive: "Implemented fully inside Handshake Studio Rust/state engines."
  provider_adapter: "Requires local ML or external provider runtime behind typed request/receipt boundary."
  optional_integration: "External service/account/cloud/collaboration/template integration; core editing must work without it."
  compatibility_shim: "Local representation for interoperability or metadata compatibility with external standards/services."
  omit_for_now: "Documented non-goal until operator explicitly accepts scope."
gate: "No AI/cloud/collaboration feature is implementation-ready until posture, fallback, receipt, and offline behavior are defined."
```
