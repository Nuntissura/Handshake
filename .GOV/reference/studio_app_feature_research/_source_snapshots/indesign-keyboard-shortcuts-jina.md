Keyboard shortcuts
Last updated on Jun 2, 2026

Learn about keyboard shortcuts to speed up your Adobe InDesign workflow and work more efficiently.

InDesign includes keyboard shortcuts that help you work more efficiently, many of which are displayed alongside menu commands. You can use the default shortcut sets for InDesign, Illustrator, or Photoshop, or create and share your own on the same platform.

Use Show Set in the Keyboard Shortcuts dialog box (Edit > Keyboard Shortcuts) to generate a printable list of your current shortcuts. This is especially useful for custom shortcut sets.
