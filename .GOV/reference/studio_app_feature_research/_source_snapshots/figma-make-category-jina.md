## Jump right in with these quick prompt ideas

### Task tracker

"Make a task-tracking app where I can save my tasks. It should include time-tracking functionality so I can enter how long I spent on each task."

Unpack this prompt

*   Data persistence
*   Defined requirements
*   UX considerations

### Career dashboard

"Build a job application tracker that uses the LinkedIn API to import job listings and lets users track application status."

Unpack this prompt

*   Third-party API usage
*   Data persistence
*   Layout agnostic

### Pixel art creator

"Build a pixel art design tool that allows users to create art in a 24x24, 32x32, and 64x64 pixel canvas using preset color palettes."

Unpack this prompt

*   Solving specific problem
*   Defined requirements
*   Image exporting
