![Image 1: Montage of new Figma features](https://cdn.sanity.io/images/599r6htc/regionalized/afc9f3fa873586b43f0f708ab372c4b2f7fb4385-2988x1680.jpg?w=2988&h=1680&q=75&fit=max&auto=format)

We recently announced new features and capabilities that expand what you can do in Figma. Here’s everything we shared at Config 2026:

**Create with new materials.** Motion, depth, texture, and code — all on the canvas now.

    *   **Motion**: Create precise, expressive animations in the timeline or with the Figma agent. Build out reusable systems, and ship dev-ready animations. [Learn more](https://www.figma.com/blog/introducing-figma-motion/).
    *   **3D transforms**: Give your designs and images 3D dimension and depth. Combine with motion to make objects move like they do in the real world. [Beta signup](https://www.figma.com/config-betas/)
    *   **Shaders**: Describe what you want and our agent will build it for you—shareable and ready to bring texture to your files. [Learn more](https://www.figma.com/blog/agent-custom-tools-context-skills/).
    *   **Code layers**: Prompt interaction ideas, compare directions, and dial in the details—starting from designs or your codebase. [Beta signup](https://www.figma.com/config-betas/)

**Create custom tools.** The Figma agent connects to your tools, your files, and your team.

    *   **Agent skills**: Add skills, attachments, or connectors to help the Figma agent help you — more context for the agent, more control for you. [Learn more](https://www.figma.com/blog/agent-custom-tools-context-skills/).
    *   **Agent in FigJam and Slides**: Generate boards and diagrams in FigJam and draft and bulk-edit decks in Slides. [Beta signup](https://www.figma.com/config-betas/)
    *   **Generative plugins**: Tell the Figma agent what you need and let it generate custom tools for your creative work. [Learn more](https://www.figma.com/blog/agent-custom-tools-context-skills/).
    *   **Figma Weave tools**: Get quality assets on repeat with tools that transform any visual — style transfer, perspective shifts, and more, without leaving Figma. [Learn more](https://www.figma.com/blog/connecting-figma-and-weave/).
    *   **Weave workflows**: Create and publish Weave workflows as a tool or a template file for others to use on the Figma Community. [Try them out](https://www.figma.com/blog/connecting-figma-and-weave/).

[Explore everything we launched at Config in our recap blog post.](https://www.figma.com/blog/config-2026-recap/)

## Search the web in the Figma design agent

New release

Figma

AI

Design  Web search is now available in the Figma design agent. Pull in live web context, find best practices, and populate designs with real-world content instead of placeholders, all without leaving your file. To get started, users can prompt "search the web" in the chat or turn on web search in the plus menu.

For admins: Org admins on the Organization and Enterprise plans can manage web search access in settings. Web search is enabled by default in the organization, but individual users must toggle it on in chat.

[Learn more about web search](https://help.figma.com/hc/en-us/articles/39715554287255-Search-the-web-in-Figma-Make) and [access the agent beta](https://help.figma.com/hc/en-us/articles/34932042346775-How-do-I-access-the-AI-agent-beta-in-Figma-Design) in Figma Design.

## Workspace-level Web Publishing for Make and Sites

Update

Figma Make

Figma Sites

Administration  

Starting today, Org admins can now manage web publishing permissions for Make and Sites files at the workspace level:

    1.   Set an organizational-level policy that applies to all files by default
    2.   Optionally override that policy for files in specific workspaces

This means each workspace gets the right level of access without compromising the most security-conscious teams.

[Learn more in the help center.](https://help.figma.com/hc/en-us/articles/31242876956183-Manage-web-publishing-for-an-organization)

## Capture webpages as editable layers with the Chrome extension

Update

Figma

Design

Websites  You can now bring your websites onto the canvas as structured layers with the Figma Chrome extension. Copy the full page or selected elements, then paste into Figma to reference and riff on, no coding agent needed. The ability to generate designs using your design system is coming soon.

To get started, [install the extension](https://chromewebstore.google.com/detail/figma/fkmaohpngenfoccdgceedjkfhkdcohmg) and sign in with your Figma account. This feature is currently in beta and available only on paid plans. 
[Learn more in the help center.](https://help.figma.com/hc/en-us/articles/40826832449303-Capture-web-pages-to-layers-with-the-Figma-Chrome-extension)
