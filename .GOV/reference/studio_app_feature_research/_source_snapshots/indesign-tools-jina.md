# View and select tools

Last updated on Jun 2, 2026

Learn how to access tools on Adobe InDesign by clicking visible icons or revealing hidden tool options.

The InDesign toolbox provides quick access to selection, drawing, type, transformation, and navigation tools. Understanding how to display and navigate the toolbox helps you work more efficiently.

The toolbox appears by default as a single vertical column. Some tools have related hidden tools indicated by small arrows. You can temporarily switch between tools using keyboard shortcuts.

## View and select visible tools from the toolbox

Select Window>Tools.

The toolbox appears in your workspace. You can drag it by its top edge to reposition it.

Select the desired tool icon in the toolbox.

Hover over a tool to see its name and keyboard shortcut in the tooltip.

Note

Turn off tool tips by selecting None from the Tool Tips menu in Edit>Preferences>Interface (Windows) or InDesign>Preferences>Interface (macOS).

## Access hidden tools

Hidden tools are grouped with related tools. For example, the Rectangle tool shares space with the Ellipse  tool and the Polygon tool.

Position your pointer over a tool with a small arrow on the lower-right.

Long press or right-click the main tool to view the hidden tools.

## Switch tools temporarily

With one tool selected, press and hold the keyboard shortcut for a different tool.

Perform your action while holding the keyboard shortcut.

Release the keyboard shortcut to return to the previous tool.

## View tool hints

The Tool Hints panel provides context-sensitive information about how modifier keys, such as Shift, Alt (Windows), or Option (macOS), affect the selected tool's behavior.

Select Window>Utilities>Tool Hints.

Select any tool in the toolbox to see its description, modifier keys, and shortcuts.
