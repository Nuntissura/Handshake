# Customize toolbar

Last updated on Feb 23, 2026

Learn how to customize the toolbar and organize your tools and groups in Adobe Photoshop.

The Photoshop toolbar provides quick access to commonly used tools. Add, remove, and rearrange tools to suit your workflow. Customizing your toolbar can help you create a more efficient workspace.

Select Edit**>**Toolbar to open the Customize toolbar dialog box.

In the dialog box, organize the related tools in groups for easier access:

*   Drag and drop tools and groups to reorganize the toolbar.
*   Move less frequently used tools to Extra Tools.

![Image 10: Customize Toolbar dialog box with tools in Toolbar and Extra Tools sections, highlighting configuration icons in the Show section.](https://helpx-prod.scene7.com/is/image/HelpxProd/Customize-Toolbar-dialog-box-with-tools-in-Toolbar?$pjpeg$&jpegSize=300&wid=1600)

Customize your workspace by selecting which tools remain visible or which ones to move to Extra Tools.

![Image 11: Customize Toolbar dialog box with tools in Toolbar and Extra Tools sections, highlighting configuration icons in the Show section.](https://helpx-prod.scene7.com/is/image/HelpxProd/Customize-Toolbar-dialog-box-with-tools-in-Toolbar?$pjpeg$&jpegSize=300&wid=1600)

Customize your workspace by selecting which tools remain visible or which ones to move to Extra Tools.

Select Toggle, which shows extra tools in the last toolbar slot to access Extra Tools in the toolbar.

Select Save Preset to save your custom toolbar layout.

Select Load Preset to open a previously saved custom toolbar.

Select Restore Defaults to restore the default toolbar.

Select Clear Tools to move all the tools to Extra Tools.

Select Done to save your changes or Cancel to discard them.
